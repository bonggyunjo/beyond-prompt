UI/UX 매뉴얼 없이 에이전트에게 프론트엔드를 맡겨본 실험: 딱 '기능만 돌아가는' 화면을 피하려면

1. 실험: 아무런 UI/UX 프로세스 없이 에이전트에게 프론트를 맡겨보았다 roomora 프로젝트를 진행하며 백엔드와 프론트엔드를 빠르게 구축해 보았다. 사실 프론트엔드도 명확한 기준과 프로세스를 갖춰야 완성도가 나온다는 건 당연한 이야기지만, 일부러 하나의 실험을 해보고 싶었다. “에이전트에게 아무런 UI/UX 매뉴얼이나 디자인 프로세스 없이, 기능 구현 지시만 던졌을 때 프론트엔드를 어느 수준까지 뽑아낼까?” 결론부터 말하면 처참했다. 말 그대로 “딱 기능만 돌아가는 정도"였다. 구현을 마치고 화면을 띄우자마자 두 가지 문제가 곧바로 눈에 들어왔다. UI/UX가 전반적으로 너무 촌스럽다. 키워드, 문구, 색감까지 전반적으로 ‘AI가 만든 티’가 너무 강하게 난다. 백엔드는 아키텍처나 계층 구조, API 스펙, 테스트 규칙만 잘 잡아줘도 어느 정도 일정한 품질이 나온다. 반면 프론트엔드는 시각적 위계나 사용자 흐름, 여백 규칙, 문구 톤을 지정해 주지 않으면 에이전트가 흔한 기본 템플릿 감성으로 화면을 채워버리기 때문에 체감 완성도가 급격히 떨어졌다. ...
